# javascript-racingcar-precourse

## 기능 목록

### 1. 입력기능

- [x] 자동차 이름 입력받기
- [x] 쉼표(,)로 구분된 자동차 이름 문자열 입력
- [x] 입력값 검증
  - [x] 각 이름이 5자 이하인지 검증
  - [x] 빈 이름이 있는지 검증
  - [x] 검증 실패시 "[ERROR]" 메시지와 함께 Error 발생
- [x] 시도 횟수 입력받기
  - [x] 숫자인지 확인
  - [x] 양수인지 확인
  - [x] 검증 실패시 "[ERROR]" 메시지와 함께 Error 발생

### 2. 게임 진행

- [x] 각 자동차는 0~9 사이의 랜덤 값을 뽑는다.
  - [x] Random.pickNumberInRange(0, 9)를 사용한다.
  - [x] 랜덤 값이 4 이상이면 전진, 아니면 정지한다.
  - [x] 매 시도마다 각 자동차의 전진 상태를 출력한다.
  - [x] 예시: `pobi : --`

### 3. 결과 출력

- [x] 모든 시도가 끝난 뒤 최종 우승자를 출력한다.
  - [x] 가장 많이 전진한 자동차가 우승자이다.
  - [x] 공동 우승자일 경우 쉼표(,)로 구분하여 출력한다.
  - [x] 예시: `최종 우승자 : pobi, jun`

### 4. 테스트 기능

- [x] 자동차 이름 검증 테스트
  - [x] 5자 초과 이름 입력 시 에러
  - [x] 빈 이름 입력 시 에러
  - [x] 정상 입력 테스트
- [x] 시도 횟수 검증 테스트
  - [x] 숫자가 아닌 입력 시 에러
  - [x] 음수 입력 시 에러
  - [x] 정상 입력 테스트
- [x] 자동차 전진 로직 테스트
  - [x] 무작위 값 4 이상일 때 전진
  - [x] 무작위 값 4 미만일 때 정지
- [x] 우승자 판별 테스트
  - [x] 단독 우승자
  - [x] 공동 우승자
